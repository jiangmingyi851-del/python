# 单调栈原理详解

## 一、什么是单调栈？

**单调栈**是一种特殊的栈结构，它保持栈内元素的**单调性**（递增或递减）。在解决问题时，我们利用这种单调性来高效地找到每个元素左边或右边第一个比它大（或小）的元素。

### 基本特性：
- **单调递增栈**：栈内元素从栈底到栈顶**递增**
- **单调递减栈**：栈内元素从栈底到栈顶**递减**

## 二、单调栈的核心思想

### 关键点：
1. **维持单调性**：在压入新元素前，弹出破坏单调性的元素
2. **利用弹出的时机**：当元素被弹出时，可以确定它的某些边界信息
3. **时间复杂度**：每个元素最多入栈一次、出栈一次，所以是 O(n)

## 三、应用场景示例

### 示例1：找到每个元素右边第一个比它大的元素

```python
def nextGreaterElement(nums):
    """
    返回每个元素右边第一个比它大的元素，如果没有则返回-1
    nums = [2, 1, 5, 6, 2, 3]
    返回: [5, 5, 6, -1, 3, -1]
    """
    n = len(nums)
    result = [-1] * n
    stack = []  # 单调递减栈，存储索引
    
    for i in range(n):
        # 当前元素 > 栈顶元素，找到了栈顶元素的"下一个更大元素"
        while stack and nums[i] > nums[stack[-1]]:
            idx = stack.pop()
            result[idx] = nums[i]
        stack.append(i)
    
    return result
```

**执行过程**：
```
初始: nums = [2, 1, 5, 6, 2, 3]
步骤:
1. i=0: stack=[], 压入0 -> stack=[0]
2. i=1: nums[1]=1 < nums[0]=2, 压入1 -> stack=[0,1]
3. i=2: nums[2]=5 > nums[1]=1, 弹出1, result[1]=5
         nums[2]=5 > nums[0]=2, 弹出0, result[0]=5
         压入2 -> stack=[2]
4. i=3: nums[3]=6 > nums[2]=5, 弹出2, result[2]=6
         压入3 -> stack=[3]
5. i=4: nums[4]=2 < nums[3]=6, 压入4 -> stack=[3,4]
6. i=5: nums[5]=3 > nums[4]=2, 弹出4, result[4]=3
         nums[5]=3 < nums[3]=6, 压入5 -> stack=[3,5]
结束: result = [5, 5, 6, -1, 3, -1]
```

## 四、在LeetCode 84（柱状图最大矩形）中的应用

### 问题转换：
对于每个柱子，我们想找到：
- 左边第一个比它矮的柱子（左边界）
- 右边第一个比它矮的柱子（右边界）
- 矩形的宽度 = 右边界 - 左边界 - 1
- 矩形面积 = 高度 × 宽度

### 单调递增栈解法：

```python
def largestRectangleArea(heights):
    """
    计算柱状图中最大矩形的面积
    heights = [2, 1, 5, 6, 2, 3]
    最大面积为10（高度为5×宽度2，或高度为2×宽度5等）
    """
    # 在末尾添加高度0，确保所有柱子都能被弹出计算
    heights.append(0)
    stack = []  # 单调递增栈，存储索引
    max_area = 0
    
    for i in range(len(heights)):
        # 当前柱子比栈顶柱子矮，说明栈顶柱子的右边界找到了
        while stack and heights[i] < heights[stack[-1]]:
            # 弹出栈顶柱子，计算以它为高度的最大矩形
            height = heights[stack.pop()]
            
            # 计算宽度：
            # 如果栈为空，说明左边没有更矮的柱子，左边界为-1
            # 否则左边界是新的栈顶元素（第一个比当前柱子矮的左边柱子）
            width = i if not stack else i - stack[-1] - 1
            
            max_area = max(max_area, height * width)
        
        stack.append(i)
    
    heights.pop()  # 恢复原数组
    return max_area
```

## 五、在LeetCode 85（最大矩形）中的应用

### 思路转换：
1. 将矩阵的每一行视为柱状图的底部
2. 计算以当前行为底时，每一列的高度（连续'1'的个数）
3. 对每一行应用LeetCode 84的解法

```python
def maximalRectangle(matrix):
    if not matrix or not matrix[0]:
        return 0
    
    rows, cols = len(matrix), len(matrix[0])
    heights = [0] * (cols + 1)  # 多一个0作为哨兵
    max_area = 0
    
    for i in range(rows):
        # 更新高度数组
        for j in range(cols):
            heights[j] = heights[j] + 1 if matrix[i][j] == '1' else 0
        
        # 使用单调栈计算当前行的最大矩形面积
        stack = []
        for j in range(cols + 1):  # 注意遍历到cols，因为有哨兵
            while stack and heights[j] < heights[stack[-1]]:
                height = heights[stack.pop()]
                width = j if not stack else j - stack[-1] - 1
                max_area = max(max_area, height * width)
            stack.append(j)
    
    return max_area
```

## 七、常见问题类型

1. **下一个更大/更小元素**：使用递减/递增栈
2. **柱状图最大矩形**：递增栈，找左右边界
3. **接雨水问题**：使用递减栈计算凹槽
4. **最大矩形面积**：转化为多个柱状图问题

## 八、复杂度分析

- **时间复杂度**：O(n)，每个元素最多入栈一次、出栈一次
- **空间复杂度**：O(n)，栈的空间开销

## 九、关键要点总结

1. **单调性选择**：根据问题决定使用递增栈还是递减栈
2. **哨兵技巧**：在数组头尾添加特殊值简化代码逻辑
3. **索引存储**：通常存储索引而不是值，方便计算距离
4. **弹出时机**：当新元素破坏单调性时，弹出栈顶元素并计算
5. **边界处理**：注意栈为空时的特殊情况
