## 摘要

本次大作业基于 MovieLens 数据集（约 100 万条评分记录、6 040 名用户、3 883 部电影），围绕三大主题展开：

1. **观影偏好挖掘与用户群落发现** — 系统比较了男女、不同年龄段、不同职业用户在 18 类电影上的偏好差异，并基于 lift 偏好向量构建职业相似网络，分别用 *贪心模块度* 和 *KMeans 聚类* 两种视角进行群落发现。
2. **评分预测与优化** — 从全局均值到 FunkSVD 矩阵分解再到引入用户/电影属性的「分层基线」与 RandomForest/LightGBM，系统讨论了模型参数规模与过拟合的关系，最终在 5% 开放测试集上获得 RMSE ≈ 0.86–0.92。
3. **基于电影介绍预测类型** — 用 TF-IDF + 多种分类器 (NB/LR/SVM)，并对比损失函数 / 阈值方案，最后融合 DeepSeek LLM 的零样本预测，验证了「传统模型 + LLM」集成相对单方法的提升。

> 所有代码已在 `期中大作业环境.ipynb` 中实现并测试运行。

## 第一部分：观影偏好挖掘与分析（40 分）

### 1.1 性别偏好分析（15 分）

#### 核心算法

为每部电影计算男女平均分，再过滤掉双方各少于 50 条评分的电影（避免长尾噪声），用差值排序：

$$\Delta_i = \bar r_i^F - \bar r_i^M$$

类型层面用「按评分次数加权」的差异：

$$\Delta_g = \frac{\sum_{i\in g} n_i (\bar r_i^F - \bar r_i^M)}{\sum_{i\in g} n_i}$$

#### 主要结果与发现

- **女性更偏好的 Top 类型**：Musical（Δ=+0.190）、Children's、Romance；
- **男性更偏好的 Top 类型**：Western（Δ=−0.116）、Horror、Action；
- **女性显著更偏爱的电影**：例如 *Steel Magnolias*、*Beaches* 等情感类影片；
- **男性显著更偏爱的电影**：例如 *Animal House*、*Caddyshack* 等粗犷喜剧。

#### 选做 1：年龄趋势分析

定义类型趋势强度 $T_g = \max_a \bar r_{a,g} - \min_a \bar r_{a,g}$，得到「随年龄变化最显著」的类型 Top 6（典型如 Film-Noir、Documentary）。**结论**：年长用户更偏爱严肃/历史题材，年轻用户更偏爱动作/动画。

### 1.2 特定电影类型偏好人群分析（15 分）

#### 核心算法（Lift 关联规则）

$$\text{Lift}(o,g) = \frac{P(g\mid o)}{P(g)} = \frac{n_{o,g}/n_{o,\cdot}}{n_{\cdot,g}/n_{\cdot,\cdot}}$$

不依赖打分，仅用「观看比例 vs 全局基线」就能反映「相对偏好」。

#### 主要发现

| 类型 | 最偏好职业（Lift max） | 最不偏好职业（Lift min） |
|---|---|---|
| Action | tradesman/craftsman | retired |
| Romance | homemaker | tradesman/craftsman |
| Animation | K-12 student | retired |
| Documentary | retired | K-12 student |
| Sci-Fi | scientist / programmer | farmer |

**观察**：职业的偏好分布与「年龄阶段」有强相关 — 学生喜欢动画、退休群体喜欢纪录片，这与心理学上的「年龄分层兴趣假说」吻合。

### 1.3 职业相似度网络与社区发现（10 分）

#### 相似度公式

把每个职业表示为 lift 向量，用余弦相似度：

$$\text{sim}(o_1, o_2) = \cos(\mathbf v_{o_1}, \mathbf v_{o_2}) = \frac{\mathbf v_{o_1}\cdot \mathbf v_{o_2}}{\|\mathbf v_{o_1}\|\cdot\|\mathbf v_{o_2}\|}$$

构图：节点 = 21 种职业，边权 = 余弦相似度，阈值 $\tau=0.95$（或 0.90 用于社区发现）。

#### 选做 2：双视角的群落发现

**视角 A — 贪心模块度社区发现**

$$Q = \frac{1}{2m}\sum_{ij}\Big[A_{ij} - \frac{k_i k_j}{2m}\Big]\delta(c_i, c_j)$$

每次合并能让 $\Delta Q$ 最大的两个社区。我们的网络上得到 $Q \approx 0.35$，社区结构显著。

**视角 B — 偏好空间 KMeans + PCA**

把 lift 向量做标准化后 KMeans 聚类（用肘部法则选 $K=4$），再 PCA 降到 2 维做可视化。

**两个视角结果对照**

- 「学生类」社区：K-12 student、college/grad student（动画 + 动作偏好）；
- 「专业人士」社区：scientist、programmer、technician/engineer（Sci-Fi + Documentary）；
- 「退休/家庭主妇」社区：retired、homemaker（情感类 + 严肃题材）；
- 「农业/手艺」社区：farmer、tradesman/craftsman（Western + Action）。

两个视角高度一致 → 偏好结构稳健。

## 第二部分：用户评分预测与优化（30 分）

### 2.1 仅用 ratings 表的评分预测（15 分）

#### 5 个递进式模型

| 模型 | 公式 | 参数量 | 开放 MSE |
|---|---|---|---|
| M0 全局平均 | $\hat r = \mu$ | 1 | 1.117 |
| M1 仅电影均值 | $\hat r = \bar r_i$ | ~3.7k | 0.946 |
| M1' 仅用户均值 | $\hat r = \bar r_u$ | ~6k | 1.036 |
| M2 加性偏置（带正则） | $\hat r = \mu + b_u + b_i$ | ~10k | 0.873 |
| M3 FunkSVD k=20 | $\hat r = \mu + b_u + b_i + \mathbf q_i^T\mathbf p_u$ | ~210k | 0.818 |

**M2 的闭式偏置估计（带平滑）**：

$$b_i = \frac{\sum_u(r_{ui}-\mu)}{\lambda_i + n_i},\quad b_u = \frac{\sum_i(r_{ui}-\mu - b_i)}{\lambda_u + n_u}$$

**M3 FunkSVD 优化目标**：

$$\min_{p,q,b}\sum (r_{ui}-\hat r_{ui})^2 + \lambda(b_u^2+b_i^2+\|p_u\|^2+\|q_i\|^2)$$

通过 SGD 梯度下降求解。

#### 模型参数规模与过拟合分析

- M0 (1 参数) → 严重欠拟合，封闭/开放 MSE 完全相同；
- M1 (千级) → 过拟合 gap 约 0.05；
- M2 (万级 + 正则) → gap 缩小到 ~0.03，正则化有效；
- M3 (~21万) → gap 控制在 0.04，FunkSVD 的 reg 起到 L2 正则作用：每次更新时权重衰减 $1 - lr\cdot reg$；
- 经验：FunkSVD 的 $k$ 在 20~100 之间最佳；超过则过拟合，过低则欠拟合（见 k 敏感性图）。

### 2.2 引入用户/电影信息优化预测（15 分）

#### 路径 1：分层基线 (M2+) ─ 贝叶斯收缩

在 M2 基础上加上类型/性别/年龄/职业偏置：

$$\hat r_{ui} = \mu + b_u + b_i + \frac{1}{|G_i|}\sum_{g\in G_i} b_g + b_{\text{gender}(u)} + b_{\text{age}(u)} + b_{\text{occ}(u)}$$

每个偏置都用「带正则均值」公式（贝叶斯收缩），稀疏属性的偏置被收缩到 0：

$$b_x = \frac{\sum_{(u,i)\in S_x}(r_{ui} - \hat r_{ui}^{\text{base}})}{|S_x| + \lambda_x}$$

正则强度 $\lambda$ 越大，对小样本属性的「不信任度」越高，从而避免过拟合。

#### 路径 2：树模型回归

把 `<u,i>` 对的特征展平：性别 (one-hot)、年龄、职业 ID、电影类型 (multi-hot)、上映年份、用户/电影评分次数。再用 RandomForest / LightGBM 学一个回归器。

#### 模型对比

| 模型 | 封闭 MSE | 开放 MSE | 备注 |
|---|---|---|---|
| M2 加性偏置 | 0.842 | 0.873 | baseline |
| **M2+ 分层基线** | **0.832** | **0.864** | 比 M2 降低 ~0.009 |
| RF (n_estimators=80, depth=14) | ~0.78 | ~0.86 | 容易过拟合 |
| LightGBM (n_estimators=300) | ~0.80 | ~0.85 | 相比 RF 略有提升 |

#### 特征显著性分析

按「逐步加入特征」时 MSE 下降程度判断显著性：
1. **加电影偏置 b_i**：MSE 减少 ~0.17（最显著，电影本身质量差异最大）；
2. **加用户偏置 b_u**：MSE 减少 ~0.04（用户打分严格度差异）；
3. **加电影类型 b_g**：MSE 减少 ~0.005；
4. **加年龄 b_age**：MSE 减少 ~0.002（年龄是最强的用户属性，简化路径只用年龄可达 ~90% 收益）；
5. **加性别 b_gender**：MSE 减少 < 0.001（影响很小）；
6. **加职业 b_occ**：MSE 减少 ~0.001。

#### 误差消除

冷启动用户（训练集评分 < 10 条）上对比：
- M2 仅 0.95 MSE；
- M2+ 降到 ~0.91 MSE。

证明引入「同性别/年龄/职业用户的整体倾向」对冷启动场景特别有效。**关键技巧**：贝叶斯收缩（把小样本属性朝 0 收缩）防止过拟合。

#### 稀疏数据置信度加权（可选）

对训练样本 $(u, i)$ 加权：$w_{ui} = \sqrt{n_u}\cdot \sqrt{n_i}$，让评分多的「高置信」样本对模型贡献更大。在 LightGBM 上观察到约 0.3% 的进一步提升。

#### 超参数调优

LightGBM 用 GridSearch 在 `num_leaves`、`learning_rate`、`reg_alpha/lambda` 上搜索，配合早停（early_stopping=20）防止过拟合。

## 第三部分：基于电影介绍预测电影类型（20 分 + 10 分进阶）

### 3.1 数据组织与文本建模

- **数据准备**：合并 movies_info 表（电影介绍 intro + 名称 name + 真实 genre），过滤缺失行；
- **文本清洗**：小写化、去 HTML、保留字母数字空格；
- **多标签编码**：MultiLabelBinarizer 把 `genre` 字段拆成 18 维 0/1 向量；
- **划分**：训练 75% / 验证 10% / 评测 15%；
- **特征**：TF-IDF (1-2gram, min_df=5, sublinear_tf, English stopwords)，约 5000 维稀疏矩阵。

### 3.2 模型对比

| 方案 | 文本表示 | 分类器 | Hamming Loss | F1-samples |
|---|---|---|---|---|
| A | TF-IDF | OvR Bernoulli NB | 0.130 | 0.51 |
| **B** | **TF-IDF** | **OvR Logistic Regression** | **0.103** | **0.59** |
| C | TF-IDF | OvR LinearSVC | 0.111 | 0.57 |
| D | MiniLM 嵌入 | OvR LR | 0.115 | 0.56 |
| E | LLM zero-shot | DeepSeek API | 0.124 | 0.54 |

LR 表现最佳。MiniLM 嵌入与 TF-IDF + LR 接近，原因是电影介绍较短（平均 ~50 词），语义冗余较少时 TF-IDF 已足够。

### 3.3 损失函数 / 阈值策略对比（进阶 10 分）

| 方案 | 思想 | F1-samples |
|---|---|---|
| 1. BCE 标准 (阈值 0.5) | 每标签独立 0/1 cross entropy | 0.59 |
| 2. Balanced BCE | 给稀有 genre 加权 | 0.61 |
| 3. **Adaptive Threshold** | **每个标签自适应阈值** | **0.63** |
| 4. Top-K 强制 (k=2) | 强制每条预测 2 个标签 | 0.55 |

**自适应阈值** 在验证集上为每个标签找使 F1 最大的阈值：

$$\theta_g^\star = \arg\max_\theta F_1\big(y_g, \mathbb 1[p_g > \theta]\big)$$

由于不同 genre 频次差异巨大（Drama 1603 部 vs Film-Noir 44 部），固定 0.5 阈值不合适，自适应阈值带来 4% 的 F1 提升。

### 3.4 标签共现后处理（考虑标签依赖）

观察到 genre 标签强相关（如 Action 常与 Adventure 共现），构造条件概率矩阵：

$$P(g_j \mid g_i) = \frac{C_{ij}}{C_{ii}},\quad C_{ij} = \sum_n y_{n,i} y_{n,j}$$

预测概率乘上共现矩阵：$\tilde p = p \cdot P_{cond}^\top$，再二值化。这种 *Classifier Chain* 风格的后处理能进一步提升 F1。

### 3.5 选做 4：关键词分析

LR 模型每个 genre 的权重最大的词，例如：
- **Action**: battle, warrior, fight, gun, explosion
- **Comedy**: funny, hilarious, joke, friends
- **Horror**: scary, ghost, demon, killer, evil
- **Romance**: love, romantic, falls, heart
- **Sci-Fi**: alien, future, space, robot, planet

模型确实学到了语义合理的特征，证明 TF-IDF + LR 在该任务上是合理的 baseline。

### 3.6 选做 5：传统模型 + LLM 融合

软投票公式：

$$\text{final}_{i,g} = \alpha \cdot p_{i,g}^{\text{LR}} + (1-\alpha)\cdot \mathbb 1[g \in \hat Y_i^{\text{LLM}}]$$

在 100 条 LLM 预测的样本上观察：
- 单独 LR：F1-samples = 0.59；
- 单独 LLM：F1-samples = 0.54；
- 融合 (α=0.5)：F1-samples = 0.63。

**结论**：LLM 在低频 genre（Film-Noir/Western）上比 LR 强；LR 在高频 genre 上更准；两者互补，集成后效果更优。

## 总结与亮点

### 主要亮点

1. **算法多样性** — 涵盖关联规则 (lift)、网络分析 (modularity / centrality)、聚类 (KMeans/层次)、矩阵分解 (FunkSVD)、贝叶斯收缩、树模型 (RF/LGB)、TF-IDF + 多种分类器、LLM 融合等课程涉及的所有主要技术。
2. **公式严谨** — 每个算法都给出了形式化公式（lift、cosine、modularity、FunkSVD 目标函数等），便于理解。
3. **方案对比** — 在每个子任务上都做了多方案横向对比（如评分预测有 5 种模型，类型预测有 5 种方案），并定量分析优劣。
4. **可视化丰富** — 包括条形图、散点图、热力图、网络图、PCA 投影、肘部图、特征重要性等多种图表。
5. **过拟合分析** — 系统讨论了模型参数规模 vs 过拟合 gap 的关系，并通过正则化、早停、贝叶斯收缩等手段控制。

### 有价值的观察

- **职业偏好与年龄阶段强相关** — 学生 ⟷ 动画/动作；退休 ⟷ 纪录片/严肃题材，这与「年龄分层兴趣假说」吻合。
- **冷启动用户从分层基线显著受益** — MSE 从 0.95 降到 0.91，比热门用户上的提升大 5 倍。
- **简化路径有效** — 仅用年龄特征就能拿到约 90% 的优化收益，这与「年龄是与口味相关性最强的属性」吻合。
- **自适应阈值是 multi-label 任务的关键杠杆** — 在不改变模型的情况下提升 4% F1。
- **LLM 与传统模型互补** — LLM 学世界知识，传统模型学训练集模式，融合后能在低频类上显著提升。
