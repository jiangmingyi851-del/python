# 并查集详解及Python实现

## 什么是并查集

并查集（Union-Find）是一种树型的数据结构，用于处理一些**不相交集合**的合并及查询问题。它主要支持两种操作：

1. **查找（Find）**：确定元素属于哪个子集
2. **合并（Union）**：将两个子集合并成一个集合

## 基本概念

### 核心思想
- 每个集合用一棵树表示
- 树的根节点作为该集合的代表
- 通过路径压缩和按秩合并来优化性能

### 应用场景
- 连通性判断
- 最小生成树算法（Kruskal）
- 网络连接检测
- 社交网络中的朋友关系

## Python实现

### 基础版本

```python
class UnionFind:
    def __init__(self, n):
        # 初始化，每个元素的父节点都是自己
        self.parent = list(range(n))
    
    def find(self, x):
        # 查找根节点
        while self.parent[x] != x:
            x = self.parent[x]
        return x
    
    def union(self, x, y):
        # 合并两个集合
        root_x = self.find(x)
        root_y = self.find(y)
        if root_x != root_y:
            self.parent[root_x] = root_y
    
    def connected(self, x, y):
        # 判断两个元素是否连通
        return self.find(x) == self.find(y)
```

### 优化版本（路径压缩 + 按秩合并）

```python
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [1] * n  # 记录树的深度
    
    def find(self, x):
        # 路径压缩
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x, y):
        root_x = self.find(x)
        root_y = self.find(y)
        
        if root_x == root_y:
            return
        
        # 按秩合并
        if self.rank[root_x] > self.rank[root_y]:
            self.parent[root_y] = root_x
        elif self.rank[root_x] < self.rank[root_y]:
            self.parent[root_x] = root_y
        else:
            self.parent[root_y] = root_x
            self.rank[root_x] += 1
    
    def connected(self, x, y):
        return self.find(x) == self.find(y)
```

## 关键优化技巧

### 1. 路径压缩（Path Compression）
```python
def find(self, x):
    if self.parent[x] != x:
        self.parent[x] = self.find(self.parent[x])  # 递归压缩路径
    return self.parent[x]
```

### 2. 按秩合并（Union by Rank）
```python
def union(self, x, y):
    root_x = self.find(x)
    root_y = self.find(y)
    
    if root_x == root_y:
        return
    
    # 将深度小的树合并到深度大的树
    if self.rank[root_x] < self.rank[root_y]:
        self.parent[root_x] = root_y
    elif self.rank[root_x] > self.rank[root_y]:
        self.parent[root_y] = root_x
    else:
        self.parent[root_y] = root_x
        self.rank[root_x] += 1
```

## 实用技巧和模式

### 1. 统计连通分量数量
```python
def count_components(self):
    # 统计根节点的数量
    roots = set()
    for i in range(len(self.parent)):
        roots.add(self.find(i))
    return len(roots)
```

### 2. 获取所有连通分量
```python
def get_components(self):
    components = {}
    for i in range(len(self.parent)):
        root = self.find(i)
        if root not in components:
            components[root] = []
        components[root].append(i)
    return list(components.values())
```

### 3. 带权并查集
```python
class WeightedUnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.weight = [0] * n  # 记录到父节点的权重
    
    def find(self, x):
        if self.parent[x] != x:
            origin = self.parent[x]
            self.parent[x] = self.find(self.parent[x])
            self.weight[x] += self.weight[origin]
        return self.parent[x]
    
    def union(self, x, y, val):
        root_x = self.find(x)
        root_y = self.find(y)
        
        if root_x != root_y:
            self.parent[root_x] = root_y
            self.weight[root_x] = self.weight[y] - self.weight[x] + val
```

## 实际应用示例

### 例题1：朋友圈问题
```python
def find_circle_num(is_connected):
    n = len(is_connected)
    uf = UnionFind(n)
    
    for i in range(n):
        for j in range(i + 1, n):
            if is_connected[i][j] == 1:
                uf.union(i, j)
    
    return uf.count_components()

# 测试

    [1, 1, 0],
    [0, 0, 1]
```

### 例题2：岛屿数量
```python
def num_islands(grid):
    if not grid:
        return 0
    
    rows, cols = len(grid), len(grid[0])
    uf = UnionFind(rows * cols)
    
    directions = [(0, 1), (1, 0), (0, -1), (-1, 0)]
    count = 0
    
    for i in range(rows):
        for j in range(cols):
            if grid[i][j] == '1':
                count += 1
                for dx, dy in directions:
                    ni, nj = i + dx, j + dy
                    if 0 <= ni < rows and 0 <= nj < cols and grid[ni][nj] == '1':
                        if not uf.connected(i * cols + j, ni * cols + nj):
                            uf.union(i * cols + j, ni * cols + nj)
                            count -= 1
    
    return count
```

## 性能分析

| 操作  | 基础版本 | 优化版本 |
| ----- | -------- | -------- |
| Find  | O(h)     | O(α(n))  |
| Union | O(h)     | O(α(n))  |

其中 α(n) 是反阿克曼函数，对于所有实际应用场景，α(n) ≤ 5。

## 总结

并查集是一种高效处理连通性问题的数据结构，通过路径压缩和按秩合并可以达到近乎常数时间复杂度。在Python中实现时要注意：

1. 使用列表存储父节点和秩信息
2. 递归实现路径压缩
3. 根据具体问题选择合适的优化策略
4. 注意边界情况的处理

掌握并查集对于解决图论、连通性相关的问题非常有帮助，是算法竞赛和面试中的常考知识点。
