# Python 学习与课程资料归档

这个仓库用于归档 Python 学习笔记、算法训练代码、课程作业、考试复习资料以及少量实用工具项目。它不是一个单一的软件包，而是按学习主题和课程场景整理的资料库。

仓库内容主要面向按主题查阅、复习和复现实验：多数文件是独立脚本、Markdown 笔记、Jupyter Notebook、课程课件或课程项目数据。不同目录可能依赖不同的 Python 库，运行前建议先查看对应文件顶部的 `import` 语句或项目说明。

## 内容概览

- Python 基础语法、进阶语法、常用库和环境操作笔记
- 数据结构与算法课程课件、专题练习和复习资料
- OJ、Codeforces、LeetCode、洛谷等平台题解
- Python 程序设计课程作业、期中大作业和期末大作业
- 数据结构与算法课程作业、报告和零散练习脚本
- 月考、期末、模拟考等考试复习资料
- 可视化脚本、终端/虚拟机练习、小型工具项目

## 运行方式

多数 `.py` 文件可以直接运行：

```bash
python 文件名.py
```

如果路径中包含中文、空格或特殊字符，建议加引号：

```bash
python "学习笔记/基础语法/字符串 常见操作.py"
```

Notebook 文件建议使用 Jupyter 打开：

```bash
jupyter notebook
```

部分课程项目会用到第三方库，例如 `numpy`、`pandas`、`matplotlib`、`scikit-learn` 以及 NLP 或深度学习相关库。不同作业的依赖不完全一致，建议按具体目录和文件单独配置环境。

## 关于大文件

仓库中包含课程数据、图片、Notebook 输出和实验结果文件，体积可能比普通代码仓库更大。部分超大数据文件和压缩包未纳入仓库，以避免超过 GitHub 普通仓库的文件大小限制。

克隆或下载仓库后，如果某个课程项目提示缺少数据文件，需要结合对应作业目录中的说明或数据文件名补齐。仓库中的代码和资料主要用于学习、复习和课程项目归档。
