# Python 学习与练习仓库

这个仓库是一个 Python 学习、算法训练和课程项目归档，内容覆盖基础语法、进阶语法、数据结构与算法、在线评测题解、考试复习以及 Python 程序设计课程作业。

仓库中的文件大多是独立脚本、Notebook 或学习资料，不是一个单一的软件包。不同目录的运行环境和依赖不完全一致，适合按主题查阅、复习和复现实验。

## 内容概览

仓库主要包含以下几类内容：

- Python 语法与标准库练习
- 数据结构、算法模板和题解
- OJ、Codeforces、LeetCode、洛谷等平台题目
- Python 程序设计课程作业和大作业
- 考试复习资料、月考题、期末题
- Jupyter Notebook、数据文件、图片资源和实验报告
- 少量编辑器配置和环境操作记录

## 重点内容

### 基础语法

`基础语法/` 适合从零复习 Python 基础，文件名基本对应知识点：

- 基本输入输出：`输入.py`、`输出示例.py`
- 基础类型：`变量与数值.py`、`浮点数.py`、`类型转换.py`
- 字符串：`字符串 常见操作.py`、`字符串 格式化输出.py`、`字符串编码 索引.py`
- 容器类型：`列表.py`、`元组.py`、`字典.py`、`集合.py`
- 流程控制：`if判断.py`、`循环.py`
- 函数、模块和包：`函数与模块.py`、`异常与模块.py`、`包的管理.py`
- 面向对象和高级特性：`类与对象.py`、`装饰器,迭代器与生成器.py`
- 工程基础：`虚拟环境.py`、`读取与写入文件.py`、`调试技巧.py`

### 进阶语法

`进阶语法/` 更偏实际使用和算法实现：

- 常用库：`pandas用法.md`、`统计库.py`
- 数据结构：`堆.py`、`链表.py`、`并查集.md`、`前缀树.md`
- 算法技巧：`滑动窗口.py`、`单调栈.md`、`区间最大最小值.md`

### OJ 题目

`OJ题目/` 是按题型整理的题解区：

- `动态规划/`：最大矩阵、买两次股票、旅行商、最大上升子序列和、滑雪等。
- `图论/`：最小生成树、DAG、Dijkstra、图连通和建图类题目。
- `字符串/`：单词统计、解码、邮箱、周期问题。
- `排序与贪心/`：排序、装箱、比较大小、最大点数等。
- `搜索与回溯/`：全排列、3Sum、词梯、华容道、城堡问题、走山路等。
- `数学与模拟/`：约瑟夫问题、矩阵乘法、进制转换、复数计算、2048、雷达、蚂蚁等。
- `数据结构/`：AVL、LCA、LRU、线段树、并查集、链表、哈夫曼树、表达式、树遍历、欧拉通路等。

## 运行方式

多数 `.py` 文件可以直接运行：

```bash
python 文件名.py
```

如果路径中包含中文或空格，建议加引号：

```bash
python "基础语法/字符串 常见操作.py"
```

Notebook 文件建议使用 Jupyter 打开：

```bash
jupyter notebook
```

部分课程项目会用到第三方库，例如 `numpy`、`pandas`、`matplotlib`、`scikit-learn` 以及 NLP 或深度学习相关库。不同作业依赖不同，运行前可以先查看对应脚本或 Notebook 顶部的 `import` 语句。

## 关于大文件

仓库中包含课程数据、图片和实验结果文件。由于 GitHub 对普通 Git 仓库的单文件大小有限制，部分超大数据文件和压缩包不包含在当前仓库中。

当前仓库中仍保留了部分较大的实验文件，主要用于课程项目复现。克隆仓库时请注意仓库体积。
